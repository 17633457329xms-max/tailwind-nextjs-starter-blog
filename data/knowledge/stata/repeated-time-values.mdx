执行`xtset id year`出现`repeated time values within panel`，表示同一个面板个体在同一时间有多条记录。正确处理取决于这些记录为什么重复。

## 第一步：确认面板键

```stata
isid id year
duplicates report id year
duplicates tag id year, gen(dup)
list id year if dup > 0, sepby(id year)
```

先检查`id`是否真的是研究单位。有些企业代码在数据库切换或合并后可能不是稳定唯一键。

## 第二步：判断重复含义

- 完全重复：所有字段都相同，可能是导入或追加造成。
- 一对多合并：主数据一行匹配了明细数据多行。
- 数据层级不同：企业年数据与产品、分支或季度数据混在一起。
- 同年多次事件：事件数据本来就不是企业—年份唯一。

## 第三步：选择处理方式

完全重复可以在核验后去重；明细数据应先按理论需要聚合；一对多合并要修正键；季度数据应使用季度时间变量，而不是强行改成年。

```stata
bysort id year: gen n = _N
tab n
```

不要直接运行`duplicates drop id year, force`。它会任意保留一行，可能丢失有效信息。

## 第四步：重新验证

处理后再次执行`isid id year`，保存未匹配和异常记录清单，再设置面板并检查年份跨度。
