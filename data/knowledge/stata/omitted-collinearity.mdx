Stata显示`note: variable omitted because of collinearity`，表示在当前样本和模型中，该变量可以被其他变量或固定效应完全线性表示。被省略不一定是数据错误，关键是判断它是否符合模型结构。

## 情况一：分类变量的基准组

使用`i.industry`时，Stata必须省略一个类别作为基准，否则全部虚拟变量与常数项完全共线。这种省略是正常的，其他类别系数解释为相对基准组的差异。

```stata
reg y i.industry controls
fvset base 1 industry
```

论文中要说明基准组，不要把被省略类别描述为“没有影响”。

## 情况二：变量与固定效应完全重合

企业固定效应会吸收企业内不随时间变化的变量；年份固定效应会吸收只按年份变化、对所有个体相同的变量。如果政策只在省份—年份层级变化，再加入省份×年份固定效应，核心政策变量也可能被吸收。

先明确[固定效应模型怎么选](/methods/fixed-effects-model-selection)，再决定是否模型过度控制。不能为了保留核心系数就随意删除必要固定效应。

## 情况三：手工虚拟变量陷阱

同时加入所有类别虚拟变量和常数项会完全共线。优先使用因子变量语法：

```stata
reg y i.group controls
```

如果分类变量包含小数或错误编码，先处理[factor variables非整数报错](/stata/factor-variable-noninteger)。

## 情况四：估计样本中没有变化

变量在完整数据中有变化，但经过`if`筛选、缺失值删除或固定效应样本限制后可能只剩一个值：

```stata
summarize x if e(sample), detail
tab x if e(sample), missing
bysort firm_id: egen sd_x = sd(x)
summarize sd_x if e(sample)
```

`e(sample)`只能在成功估计后使用。若模型直接失败，应先按[no observations r(2000)](/stata/no-observations-r2000)逐层检查样本。

## 情况五：重复构造或恒等关系

总资产、负债和所有者权益等变量可能存在会计恒等关系；同时放入总量、分项和比例也可能产生完全关系。相关系数高不等于必然被省略，Stata省略针对的是当前设计矩阵中的完全共线。

## 推荐排查步骤

1. 读取回归前的`note`，记录被省略变量。
2. 判断它是否为因子变量基准组。
3. 检查变量变化层级与固定效应层级。
4. 检查估计样本中的唯一值和组内变化。
5. 检查重复变量、恒等关系和错误交互项。

## 论文中怎么处理

正常基准组不需要“修复”，只需正确说明。核心变量被固定效应吸收则意味着现有数据和设定没有可用变化，需要调整研究问题、数据或识别设计，而不是隐藏Stata提示。
