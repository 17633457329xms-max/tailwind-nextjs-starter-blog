企业创新不是单一变量。研发投入反映投入过程，专利反映可观察产出，引用和发明专利更接近质量。选择指标时要先确认研究问题关心哪一部分。

## 常见测量方式

| 指标              | 主要含义           | 常见注意事项            |
| ----------------- | ------------------ | ----------------------- |
| 研发投入/营业收入 | 创新投入强度       | 缺失值不能直接全部当作0 |
| 专利申请数        | 创新活动与产出意愿 | 申请不等于最终授权      |
| 专利授权数        | 经过审查的产出     | 与申请年份存在时间差    |
| 发明专利数        | 技术含量相对更高   | 数量通常更少、偏态更强  |
| 专利引用          | 后续影响或质量     | 受专利年龄和领域影响    |

## 对数处理

专利数量常出现大量0和右偏。实证中常使用`ln(1 + 专利数)`，但写作时要说明变换，并避免把对数系数直接解释成原始数量增加多少件。

## 时间口径

申请年份更接近企业作出创新决策的时间，授权年份受审查周期影响。若研究冲击与决策时点有关，申请口径通常更容易解释。

## 建议的变量说明

变量表中写清指标名称、计算公式、原始字段、年份口径、数据来源、缺失处理和缩尾规则。基准指标与替代指标应服务于不同维度，而不是简单重复。
