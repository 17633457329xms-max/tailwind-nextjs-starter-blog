# 正式上线部署手册（国内 SEO 与个人维护优先）

> 适用项目：`tailwind-nextjs-starter-blog`
>
> 当前预览站：`https://lw.up.railway.app/`
>
> 更新日期：2026-09-02
> 本手册只给出一条正式上线路线，不做二选一。

## 1. 固定架构与分工

正式站固定采用：**阿里云轻量应用服务器（中国大陆杭州）+ 自有 `.com` 域名 + ICP 备案 + Nginx + PM2 + GitHub Actions 自动部署**。

Railway 仅保留为预览环境，不作为正式 SEO 入口。发布链路固定如下：

```text
feature/* 开发分支 → preview 分支 → Railway 预览验收 → main 分支 → GitHub Actions → 阿里云正式站
```

正式主域名固定使用**不带 www** 的形式，例如 `https://lunwenfudao.com`；`www` 永久 301 跳转到不带 www 的主域名。当前阶段只展示经济学、管理学内容，其他学科保留代码与内容资产，但通过现有配置隐藏。

## 2. 成本预算

| 项目 | 固定选择 | 预估成本 | 说明 |
| --- | --- | ---: | --- |
| 服务器 | 阿里云轻量应用服务器，杭州，2 核 4 GB，50 GB SSD，5 Mbps，Ubuntu 24.04 | ¥500–900/年 | 以购买页实时活动价为准；50 GB 足够当前项目。 |
| 域名 | `.com`，不带 www 为主域名 | ¥60–100/年 | 购买后立即实名、备案。 |
| HTTPS | Let's Encrypt | ¥0 | 自动续期。 |
| GitHub Actions | 构建并 SSH 发布 | ¥0–少量 | 个人小型站点通常足够。 |
| Railway | 仅预览 | 按现有套餐 | 正式站稳定后可按需降配。 |
| Umami、百度统计、百度搜索资源平台 | 官方服务 | ¥0 | 用于流量、渠道和收录追踪。 |

正式站第一年通常按 **¥560–1,000** 预留，不含可选 CDN、商业图库等服务。

## 3. 购买与备案

1. 打开 [阿里云轻量应用服务器](https://swasnext.console.aliyun.com/buy#/)。
2. 选择“通用型”：**2 vCPU / 4 GiB / 50 GiB**。
3. 系统镜像选 **Ubuntu 24.04**，地域选 **杭州**。
4. 数量选 1、时长选 1 年、开启自动续费；下单前确认实例支持备案。
5. 购买 `.com` 域名，完成域名实名；在阿里云备案系统按个人网站提交备案。
6. 备案通过前可完成部署和验收，但不要把大陆服务器作为正式公开入口。

备案主体、网站名称和服务说明必须与实际一致。网站表述以研究方法指导、学习资料、写作反馈和论文润色优化一对一定制为准。

## 4. 域名、DNS 与正式 URL

以下以 `lunwenfudao.com` 为示例；实际操作时替换为自己的真实域名。

1. 在阿里云 DNS 新增 A 记录：主机记录 `@`，记录值为服务器公网 IPv4。
2. 新增 A 记录：主机记录 `www`，记录值同一 IPv4。
3. DNS 生效后在本机执行：

```bash
nslookup lunwenfudao.com
nslookup www.lunwenfudao.com
```

4. 两个结果均指向服务器 IPv4 后，再配置 Nginx 和 HTTPS。
5. 正式环境变量 `NEXT_PUBLIC_SITE_URL` 必须为 `https://lunwenfudao.com`；不再把 Railway URL 用于 canonical、sitemap 或结构化数据。

## 5. 服务器首次部署

登录服务器前，在阿里云防火墙放行 TCP `22`、`80`、`443`；**不要**向公网开放 3000。

```bash
sudo apt update
sudo apt upgrade -y
sudo apt install -y git nginx curl build-essential certbot python3-certbot-nginx
sudo useradd -m -s /bin/bash deploy
sudo usermod -aG sudo deploy
sudo su - deploy
```

安装 Node.js 20、Corepack、Yarn 3.6.1 与 PM2：

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
corepack enable
corepack prepare yarn@3.6.1 --activate
sudo npm install -g pm2
node -v
yarn -v
pm2 -v
```

为服务器读取 GitHub 仓库创建只读部署密钥：

```bash
ssh-keygen -t ed25519 -C "paper-site-readonly" -f ~/.ssh/github_deploy
cat ~/.ssh/github_deploy.pub
```

把公钥添加到 GitHub 仓库：`Settings → Deploy keys → Add deploy key`，名称填“阿里云正式站只读密钥”，不要勾选写入权限。创建配置：

```bash
nano ~/.ssh/config
```

```text
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/github_deploy
  IdentitiesOnly yes
```

```bash
chmod 600 ~/.ssh/config ~/.ssh/github_deploy
mkdir -p ~/apps/paper-site
cd ~/apps/paper-site
git clone git@github.com:你的GitHub用户名/你的仓库名.git .
git checkout main
```

创建 `~/apps/paper-site/.env.local`：

```dotenv
NODE_ENV=production
NEXT_PUBLIC_SITE_URL=https://lunwenfudao.com
NEXT_PUBLIC_UMAMI_SRC=https://cloud.umami.is/script.js
NEXT_UMAMI_ID=你的-Umami-Website-ID
```

首次构建和启动：

```bash
cd ~/apps/paper-site
yarn install --immutable
yarn typecheck
yarn lint
yarn build
pm2 start yarn --name paper-site -- serve
pm2 save
pm2 startup systemd -u deploy --hp /home/deploy
```

执行最后一条命令后，复制 PM2 输出的 `sudo env ... pm2 startup ...` 命令并执行一次。

## 6. Nginx 与 HTTPS

新建 `/etc/nginx/sites-available/paper-site`：

```nginx
server {
    listen 80;
    server_name www.lunwenfudao.com;
    return 301 https://lunwenfudao.com$request_uri;
}

server {
    listen 80;
    server_name lunwenfudao.com;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用并签发证书：

```bash
sudo ln -s /etc/nginx/sites-available/paper-site /etc/nginx/sites-enabled/paper-site
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
sudo certbot --nginx -d lunwenfudao.com -d www.lunwenfudao.com
sudo systemctl status certbot.timer
```

验收命令：

```bash
curl -I https://lunwenfudao.com
curl -I https://www.lunwenfudao.com
curl -I https://lunwenfudao.com/sitemap.xml
curl -I https://lunwenfudao.com/robots.txt
```

主域名应返回 `200`，www 应 `301` 到主域名，sitemap 和 robots 应 `200`。

## 7. GitHub 自动发布

正式发布只监听 `main`；Railway 预览只监听 `preview`。在 GitHub 仓库添加以下 Secrets：

| Secret | 内容 |
| --- | --- |
| `SERVER_HOST` | 阿里云服务器公网 IPv4 |
| `SERVER_USER` | `deploy` |
| `SERVER_SSH_KEY` | 为 GitHub Actions 专门生成的私钥全文 |
| `SERVER_PORT` | `22` |
| `SITE_DIR` | `/home/deploy/apps/paper-site` |

Actions 必须先完成安装、类型检查、lint、构建，再通过 SSH 更新服务器。服务器发布脚本固定如下：

```bash
set -e
cd /home/deploy/apps/paper-site
git fetch origin main
git pull --ff-only origin main
yarn install --immutable
yarn typecheck
yarn lint
yarn build
pm2 reload paper-site --update-env
curl -fsSI https://lunwenfudao.com/sitemap.xml
```

不得使用 `git reset --hard`。这样构建失败时不会执行 `pm2 reload`，线上仍保留上一版可用服务。每次上线后查看 GitHub Actions 绿色通过，再人工测试首页、经济学页、管理学页、文章页、搜索、sitemap 与咨询入口。

## 8. 国内 SEO 必做项

1. `sitemap.xml` 只列真实可访问、可索引的 canonical 页面；排除参数筛选页、旧 URL、预览页、404 和空内容页面。
2. 每页只输出一个 canonical，统一使用正式根域名；参数 URL 必须 301 到干净路径或 `noindex,follow`。
3. 主站 `robots.txt` 放行搜索引擎与 sitemap；Railway 预览站在正式上线后设置 `noindex`。
4. 在百度搜索资源平台添加正式域名，提交 sitemap，并安装百度统计；保留 Umami 用于轻量实时分析。
5. 核心文章必须具备：明确问题标题、真实发布日期/更新时间、作者信息、目录、结构化数据、公开数据来源、原创图表或表格、可复现代码、参考文献。
6. 当前优先收录经济学与管理学高信息增益文章；隐藏学科不进入首页入口、导航、sitemap 和相关推荐。
7. 用自然内链串联“问题 → 方法 → 数据 → 写作 → 相关文章”，不进行关键词堆砌。

## 9. 统计、监控与隐私

Umami 环境变量保持如下：

```dotenv
NEXT_PUBLIC_UMAMI_SRC=https://cloud.umami.is/script.js
NEXT_UMAMI_ID=你的-Umami-Website-ID
```

部署后用开发者工具确认 `cloud.umami.is/script.js` 与事件上报均为 2xx；如使用 CSP，至少在 `script-src` 和 `connect-src` 放行 `https://cloud.umami.is`。不要把完整 `<script>` 标签写入环境变量。

仅统计页面浏览、来源、站内搜索、复制代码、复制图表和微信/QQ 点击等事件；不向统计系统发送联系方式、聊天内容、论文全文或其他敏感资料。每天看 Umami 入口页和来源，每周看百度收录与抓取异常，每月据真实搜索词补一篇深度文章。

## 10. 备份、回滚与维护

1. GitHub `main` 是唯一正式代码来源；变更先经 `feature/*`，再进 `preview` 验收。
2. 每周备份环境文件和 Nginx 配置：

```bash
tar -czf ~/backup-paper-site-$(date +%F).tar.gz ~/apps/paper-site/.env.local /etc/nginx/sites-available/paper-site
```

3. 只保留最近 4 份备份，删除前先核对文件名与路径。
4. 发布异常时，在 GitHub 对上一条绿色提交执行 Revert，由 Actions 自动回滚；不要在线上手工修改源码。
5. 每月执行系统更新，并检查 `pm2 status`、`sudo nginx -t`、`sudo systemctl status certbot.timer`。

- [ ] 首页、经济学页、管理学页、文章页、搜索、咨询页正常。
- [ ] `robots.txt`、`sitemap.xml`、canonical、结构化数据均使用正式域名。
- [ ] Railway 仅作预览并设置 noindex；知乎、B 站、视频号、名片只投放正式根域名。
- [ ] GitHub Actions 真实发布一次并自动更新服务器。
- [ ] Umami 无痕访问可见，百度统计可见测试访问。
- [ ] 百度搜索资源平台已验证并提交 sitemap。
- [ ] HTTPS 续期、备份、PM2 自启动和回滚均已验证。

完成清单后，所有外部渠道统一使用正式根域名；Railway URL 只给自己和测试协作者使用。
