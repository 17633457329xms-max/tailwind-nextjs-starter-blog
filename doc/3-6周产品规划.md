## 1. 阶段结论

第3—6周不扩张新的产品类型，重点把第1—2周搭建的网站变成有稳定自然流量入口的内容站。本阶段新增20篇内容，严格按以下结构交付：

| 栏目         | 新增数量 | 主要搜索意图                                 |
| ------------ | -------: | -------------------------------------------- |
| 论文选题分析 |      5篇 | 选题怎么选、题目能不能做、变量与数据是否可得 |
| 实证方法     |      5篇 | 模型怎么选、因果识别、机制与稳健性如何设计   |
| Stata问题    |      5篇 | 报错定位、数据合并、模型运行和结果解释       |
| 变量字典     |      3篇 | 指标定义、计算方式、方向和适用边界           |
| 写作教程     |      2篇 | 开题报告、实证分析章节怎么写                 |
| 合计         | **20篇** | 覆盖国内经管学生高频问题词                   |

阶段产品目标不是承诺某个搜索排名，而是提高被百度、必应、360、搜狗及国产浏览器默认搜索发现、理解和点击的概率。排序最终仍取决于域名、收录、内容质量、竞争强度、用户反馈和外部推荐。

## 2. 用户与搜索场景

### 2.1 核心用户

- 正在准备开题的经管本科生和硕士生。
- 已进入实证阶段、需要选择模型或排查Stata问题的学生。
- 正在写初稿、预答辩、盲审或返修的学生。
- 需要论文语言、结构和逻辑润色优化的用户。

### 2.2 优先覆盖的搜索表达

国内用户通常直接搜索问题，不会先搜索品牌。本阶段优先覆盖：

- `硕士论文选题怎么选`、`经管论文选题`、`实证论文选题`。
- `实证分析`、`固定效应模型`、`中介效应检验`、`PSM-DID`、`工具变量法`、`断点回归`。
- `Stata type mismatch`、`Stata no observations`、`Stata合并数据报错`、`Stata共线性`。
- `托宾Q怎么算`、`企业数字化转型怎么衡量`、`ESG变量`。
- `开题报告怎么写`、`实证分析怎么写`。

每篇只解决一个主问题，相关词自然出现在标题、摘要、一级标题、正文步骤和常见问题中，不为近义词重复生成薄内容页。

## 4. 内容产品模板

每篇文章采用统一但不机械的产品结构：

1. 开头直接回答搜索问题，说明适用情境。
2. 解释核心概念和判断条件。
3. 给出可执行步骤、公式或Stata命令。
4. 列出常见误区及为什么错。
5. 提供报告或写作时应该呈现的内容。
6. 链接到相关方法、变量、代码或写作教程。
7. 以“先提交问题摘要”的轻咨询入口收尾。

标题必须与正文真实主题一致；摘要约40—70个汉字，概述页面能解决的问题，不写联系方式和夸张营销词。

每周录制2个长视频，共8个；每个长视频拆2—3个短视频，每周形成4—6个短视频，总计16—24个。

### 6.1 视频统一结构

- 前15秒：展示一个具体搜索问题或报错原文。
- 30秒内：说明该视频能解决什么、不能解决什么。
- 主体：按文章小标题讲解，并在画面中展示公式、代码或判断表。
- 结尾：引导用户搜索文章完整标题或访问对应网站页面。
- 置顶评论：放不带站内UTM覆盖的文章链接；跨平台链接使用规范UTM。

### 6.2 视频SEO命名

长视频标题优先采用“问题词 + 结果 + 限定条件”，例如：

> 固定效应模型怎么选？个体、年份和双向固定效应一次讲清

简介首段概述视频答案并放文章链接；字幕人工校对专业名词，如`reghdfe`、`PSM-DID`、`工具变量`。短视频不要使用与内容无关的热点词。

## 7. 站内转化路径

```text
国产浏览器/百度等搜索具体问题
  → 文章详情页
  → 相关方法、变量、Stata或写作页
  → 查看服务边界与交付说明
  → 提交问题摘要
  → 微信/QQ进一步沟通
```

文章正文不反复展示二维码，不用遮挡正文的弹窗。用户读完解决步骤后，再展示与当前问题相关的咨询入口。

## 8. 国内SEO产品原则

- 简体中文为默认语言，使用国内高校常用术语。
- 一个URL对应一个明确问题，不建立近义词重复页面。
- 重要信息以文字呈现，不只放图片或视频。
- 标题核心词靠前，站点品牌由全局模板补充。
- 摘要准确概括正文，避免微信号、QQ号和营销承诺。
- 使用真实发布日期、最后核验时间、作者和栏目面包屑。
- 每篇至少有2条语义相关内链，锚文本使用真实页面标题。
- 不刷点击、不买垃圾外链、不堆砌关键词、不批量制造低价值页。
- 新链接通过sitemap和百度普通收录API加快发现，但不宣称提交即可收录或获得排名。

## 9. 指标与周复盘

### 9.1 内容指标

- 新增正式文章数：20。
- 文章标题、摘要、H1、canonical完整率：100%。
- 每篇有效站内链接：至少2条。
- 代码文章构建成功率：100%。
- 移动端正文无横向溢出：100%。

### 9.2 搜索指标

- 百度已发现URL、抓取成功URL和索引URL。
- 非品牌搜索展现、点击、CTR和平均位置趋势。
- `实证分析`、`Stata`及长尾问题词对应入口页。
- 高展现低点击页面的标题和摘要优化记录。
- 收录但无展现页面的内容增补和内链调整记录。

### 9.3 转化指标

- 自然搜索入口页到第二篇内容的点击率。
- 文章页到咨询页的点击率。
- 咨询表单有效提交数。
- 微信/QQ二维码展示后的有效咨询人工核对数。
- 各视频平台带来的文章访问与回访。

## 10. 验收标准

- 两份第3—6周规划文档完成并纳入项目。
- 新增文章严格满足5+5+5+3+2，共20篇。
- 页面正文包含步骤、误区、检查清单或代码，不是关键词列表。
- 所有新增URL进入站点地图、RSS和站内搜索索引。
- 首页文章数量由实际内容自动计算。
- 生产构建、类型、Lint、路由、内链、SEO和浏览器测试全部通过。
- 本地最终站点启动，桌面和移动端无控制台错误。
